# Запуск команды Codex для DnD

## Установка

Открой корень `characters_recuit` с файлами `AGENTS.md`, `.codex/config.toml`
и `.codex/agents/*.toml`. Локальные изменения проекта сохраняются. Перед каждой
задачей тимлид проверяет текущую ветку и затронутые файлы.

Открой новую сессию актуального Codex в корне проекта. В терминале:

```sh
codex
```

Главная сессия — тимлид. Новая CLI-сессия из корня проекта читает настройки
`.codex/config.toml`: `gpt-6-sol`, reasoning `medium`. Для уже открытого чата
эти файлы не доказывают смену модели: открой новую сессию или выбери Sol
и medium в интерфейсе, затем проверь отображаемую модель. Предпочтительный
`gpt-6.1-sol` пока отсутствует в каталоге установленного CLI 0.155.0-alpha.16.3.
Специалисты: backend — Sol medium; `backend_small`, frontend, QA и DevOps — Luna high.
Состав и условия подключения приведены в `AGENTS.md`. Одновременно допускаются
два потока специалистов помимо тимлида. Файлы сами не запускают разработку.

## Обычная backend-задача

Передай главному агенту:

```text
Ты тимлид Characters Service. Проверь Git и затронутые файлы, прочитай только
относящиеся к задаче разделы ТЗ. Сам выполни небольшую правку. Для сложных прав,
транзакций или миграций подключи backend с конкретными файлами и критерием
готовности. QA подключи только для независимой проверки существенного поведения
или проектирования тестов; DevOps — только при изменении инфраструктуры.
Не повторяй аудит всего проекта и не поручай агентам одинаковый поиск.
После затронутых проверок запусти полный обязательный набор, прочитай итоговый diff,
обнови TEAM_STATUS и краткий отдельный отчёт в docs/reports/.
```

При исправлениях в пределах задачи используй существующий поток специалиста.
Передавай только конкретную ошибку и связанные файлы. Для небольшого узкого
backend-поручения при необходимости есть `backend_small` на Luna; обычно тимлид
выполняет такую правку сам. Не создавай вложенные команды.

## Наблюдение

- CLI: `/agent` для просмотра потоков специалистов.
- IDE: панель фоновых агентов, если она доступна в версии клиента.
- Главный чат: «Покажи статус команды, текущие блокеры и результаты проверок».
- docs/TEAM_STATUS.md: текущая сводка; docs/reports/: краткие отчёты по заданиям.
- Git diff и вывод команд: фактические изменения и результаты проверок.

Если Codex не запускает роли, попроси явно использовать named agents и проверь,
что .codex/ находится в открытом корне проекта; сверяй формат с документацией
своей версии: https://learn.chatgpt.com/docs/agent-configuration/subagents.

Конфигурация задаёт поведение, а не отдельные серверы, контейнеры или автономный
планировщик. Пользователь запускает сессию и задачу, главный агент координирует работу.
