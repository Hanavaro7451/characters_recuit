# Контракт API справочников и черновика, задание 07

Версия: 2026-10-06. Все пути имеют префикс `/api/v1`. Все ответы JSON,
кроме стандартных ошибок FastAPI. Запись справочников через API отсутствует.

## Справочники

| Метод и URL | Запрос | Ответ 200 | Доступ |
|---|---|---|---|
| `GET /catalog/species` | `ruleset=dnd-2024` (необязателен) | массив доступных версий видов | Любой авторизованный |
| `GET /catalog/classes` | тот же query | массив доступных версий классов | Любой авторизованный |
| `GET /catalog/backgrounds` | тот же query | массив доступных версий предысторий | Любой авторизованный |
| `GET /catalog/species/{version_id}` | положительный ID | одна версия, включая закрытую | Любой авторизованный |
| `GET /catalog/classes/{version_id}` | положительный ID | одна версия, включая закрытую | Любой авторизованный |
| `GET /catalog/backgrounds/{version_id}` | положительный ID | одна версия, включая закрытую | Любой авторизованный |

Общий ответ версии: `id`, `code`, `ruleset`, `content_version`, `name`,
`description`, `source_title`, `source_url`, `license_name`, `attribution`,
`available_for_selection`. Предыстория дополнительно возвращает
`ability_one`, `ability_two`, `ability_three`, `allow_plus_two_plus_one`,
`allow_plus_one_each`. Список содержит те же поля и сортируется по `code`,
`content_version`, `id`. На этом этапе query принимает только `dnd-2024`.
Ошибки: 401 без авторизации, 404 неизвестный ID, 422 некорректный ID/query.
Закрытая версия отсутствует в списке выбора, но доступна по ID.

## Персонаж

| Метод и URL | Запрос | Ответ | Доступ |
|---|---|---|---|
| `POST /campaigns/{campaign_id}/characters` | `{name, species_id, class_catalog_id, background_id}` | 201, `CharacterResponse` | Player действующей кампании |
| `GET /campaigns/{campaign_id}/characters/{character_id}` | нет | 200, `CharacterResponse` | Владелец Player или Master этой кампании |
| `PATCH /campaigns/{campaign_id}/characters/{character_id}` | `{expected_version, name?, species_id?, class_catalog_id?, background_id?}` | 200, `CharacterResponse` | Владелец Player, свой DRAFT, действующая кампания |

`name` после удаления крайних пробелов имеет длину 1–255. ID справочников —
положительные целые. При создании все четыре поля обязательны; сервер задаёт
`campaign_member_id` из членства авторизованного пользователя, `status=DRAFT`,
`level=1`, `version=1`. Выбранные записи должны существовать, быть доступными
и относиться к `dnd-2024`. Неизвестные поля request отклоняются.

PATCH требует положительный `expected_version` и хотя бы одно поле изменения.
Пропущенное поле остаётся прежним; явный `null` для каждого редактируемого
поля даёт 422. При изменении имени закреплённые закрытые версии не проверяются
повторно на доступность; при замене версии проверяется новая запись. Успешный
PATCH атомарно увеличивает `version` на 1. При несовпадении версии ответ 409
и данные не меняются. `status`, `level` и владелец в PATCH не принимаются.

`CharacterResponse`: `id`, `campaign_id`, `owner_user_id`, `name`, `status`,
`archive_reason`, `level`, `version`, `species`, `character_class`,
`background`, `legacy_race`, `legacy_character_class`. Три вложенные версии
имеют форму ответов справочника и могут быть `null` у старых персонажей.
Legacy-поля передают прежние текстовые значения либо `null`. Приватных
заметок в этом ответе нет.

### Ошибки и доступ

| Ситуация | Статус |
|---|---:|
| Нет/неверный access token | 401 |
| Пользователь не состоит в кампании; персонаж отсутствует/из другой кампании; Player запрашивает чужого | 404 |
| Master создаёт или меняет DRAFT; роль не позволяет действие | 403 |
| Кампания завершена для POST/PATCH; персонаж не DRAFT для PATCH; уже существует персонаж членства, включая архив; устарел `expected_version` | 409 |
| Ошибка формы запроса, явный `null`, неизвестный/закрытый/чужой редакции ID справочника | 422 |

GET разрешён в завершённой кампании и для закрытых версий. Ошибки объекта не
содержат данных чужого персонажа. Проверка членства выполняется до поиска
персонажа, а UPDATE защищён условием версии на уровне PostgreSQL.

### Матрица доступа

| Операция | Player своей кампании | Player чужой кампании | Master своей кампании | Master чужой кампании |
|---|---|---|---|---|
| Списки и версии каталога | Да | Да | Да | Да |
| Создать в активной кампании | Да, один за всё время | 404 | 403 | 404 |
| Читать персонажа | Только свой | 404 | Да, без приватных заметок | 404 |
| PATCH DRAFT в активной кампании | Только свой | 404 | 403 | 404 |

Генерация, распределение характеристик, отправка на проверку, мастерское
редактирование ACTIVE и frontend не входят в этот контракт.
