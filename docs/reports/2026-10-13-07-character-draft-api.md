## Результат

- До реализации записан [контракт API](../contracts/07-character-draft-api.md):
  URL, тела запросов и ответов, ошибки и матрица доступа.
- Добавлено чтение списков и конкретных версий видов, классов и предысторий.
  Закрытые версии доступны по ID и в уже созданном персонаже, но не предлагаются
  для нового выбора.
- Добавлены создание, получение и частичное обновление черновика. Создание
  определяет владельца по членству авторизованного Player, задаёт DRAFT,
  уровень 1 и версию 1. Уникальность членства защищена ограничением БД;
  конкурентный дубль возвращает 409.
- PATCH принимает только имя и три справочные ссылки, различает пропуск и
  явный `null`, проверяет `expected_version` атомарным UPDATE и возвращает 409
  при конфликте. Существующие записи с nullable ссылками читаются. Приватные
  заметки в ответ не включены.
- Миграция 06 исправлена после сообщения о падении Docker: она теперь
  поддерживает исходную таблицу `characters` как с `race` и
  `character_class`, так и без них. Старые строки сохраняются; исходное
  наличие и nullable колонок фиксируется для безопасного downgrade.
  Миграция 07 добавляет положительную версию персонажа.
